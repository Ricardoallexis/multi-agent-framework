# Cafetería de ejemplo

Oficina de ejemplo con datos inventados para probar la gestión de una cafetería en modo de prueba (sin gasto). Todo el contenido de esta carpeta es ficticio.

## Áreas

- **Menú (`menu`)**: prepara una propuesta de menú semanal a partir del pedido recibido y la deja lista para revisión.
- **Compras (`compras`)**: organiza la lista de productos y cantidades que hacen falta según el inventario disponible.
- **Avisos y respuestas (`avisos`)**: redacta avisos claros o prepara borradores de respuesta ante mensajes recibidos.

Cada área cuenta con su agente de redacción y una persona responsable que revisa antes de publicar o enviar.
