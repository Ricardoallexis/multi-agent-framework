# Example Café
Example office with synthetic data for trying a café workflow in test mode (no spending). Everything in this folder is fictional.

## Areas
- **Menu (`menu`)**: drafts a weekly menu from the request and leaves it ready for review.
- **Purchasing (`purchasing`)**: organizes the products and quantities needed based on the available inventory.
- **Notices and replies (`notices`)**: writes clear notices or drafts replies to received messages.
Each area has a drafting agent and a reviewer who checks the work before it is published or sent.
