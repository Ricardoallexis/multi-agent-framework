# Example School
Example office with synthetic data for trying a small school workflow in test mode (no spending). Everything in this folder is fictional.

## Areas
- **Planning (`planning`)**: prepares a lesson plan from a topic and leaves it ready for review.
- **Follow-up (`follow-up`)**: drafts private, local-only progress notes from brief observations.
- **Notices and replies (`notices`)**: writes clear notices or drafts replies to received messages.
Each area has a drafting agent and a reviewer who checks the work before it is published or sent.
