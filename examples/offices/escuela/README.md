# Escuela de ejemplo

Oficina de ejemplo con datos inventados para probar la organización de una escuela pequeña en modo de prueba (sin gasto). Todo el contenido de esta carpeta es ficticio.

## Áreas

- **Planeación (`planeacion`)**: prepara el plan de clase a partir de un tema y lo deja listo para revisión.
- **Seguimiento (`seguimiento`)**: redacta notas de avance en modo privado y solo local a partir de observaciones breves.
- **Avisos y respuestas (`avisos`)**: redacta avisos claros o prepara borradores de respuesta ante mensajes recibidos.

Cada área cuenta con su agente de redacción y una persona responsable que revisa antes de publicar o enviar.
